All files in this directory were generated specifically for this repository by
`Scripts/Level01/generate_sources.py` using deterministic mathematical geometry,
procedural patterns, and synthesized audio. No paid assets, other ALMNSY projects,
downloaded reference imagery, or external character assets were used.

The original UE template Content remains unchanged and retains Epic's terms.
Procedural artwork is a first-pass palette and modular kit, not scanned masonry
or final production art. OBJ and mesh JSON use centimetres, Z up, X forward.
Textures are 512px PNGs; ORM channels are ambient occlusion, roughness, metalness.
